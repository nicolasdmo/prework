🧠 Arquitectura del Agente

Todo agente autónomo se compone de 4 partes. Pensalo como un cuerpo: cerebro decide, manos ejecutan, bolsillo cobra/paga, reloj dispara el loop.

01
🧠

CEREBRO

Un LLM (OpenAI / Claude) recibe contexto y devuelve decisiones: "¿Sobre qué tema escribo? ¿Qué producto listo?"

02
🤖

MANOS

APIs que convierten la decisión en acción real: publicar en TikTok, listar en Gumroad, comprar ads. Llamadas HTTP, nada más.

03
💳

BOLSILLO

Tarjeta prepaga (salida) + Stripe/Mercado Pago/AdSense (entrada). El loop cierra cuando revenue recarga la prepaga.

04
⏰

RELOJ

Cron, Task Scheduler, GitHub Actions. Dispara el ciclo cada X horas. Sin reloj automático, no hay autonomía.

El loop en pseudocódigo

pseudocódigo 
cada_dia():
    contexto = leer_estado()          # qué hizo ayer, qué funcionó, plata disponible
    accion = cerebro.decidir(contexto)
    resultado = manos.ejecutar(accion)
    bolsillo.registrar(resultado)
    guardar_estado(resultado)
    if resultado.fue_un_winner:
        clonar_y_escalar(accion)

⚠️ Las 3 reglas innegociables

Si una de estas no se cumple, no es autónomo. Es un script que llamás "agente".

REGLA 01

Cero decisiones humanas en el loop diario

Si necesitás aprobar algo cada día, no es autónomo. Aprobás políticas (ej: "no gastes más de USD 5/día"), no decisiones individuales.

REGLA 02

Estado persistente fuera del proceso

El agente lee su memoria de un archivo (JSON, SQLite, Sheet). Si el server se cae, levanta y sigue donde quedó.

REGLA 03

Kill switch + límite de gasto

Antes de cualquier gastar() hay un if total > limite: return. Te salva de despertar con USD 200 quemados por un bug.

🗓️ Plan operativo — 14 días

DÍA 0 · SETUP
Abrir cuentas + cargar prepaga (2–3 hs)
  • OpenAI Platform → sacar API key, cargar USD 5
  • TikTok / YouTube / Instagram → cuentas nuevas dedicadas al nicho
  • Amazon Associates / Hotmart / Mercado Libre afiliados
  • GitHub → repo para correr el agente con Actions (gratis)
  • Prepaga: cargar USD 20 inicial
DÍA 0 · NICHO
Elegir el nicho del primer agente
Esta es la única decisión que requiere tu criterio humano. Reglas: te interesa, tiene afiliados de USD 20+, no es ultra-saturado, tiene audiencia en Shorts. Ejemplos que funcionan: gadgets de cocina, accesorios mascotas, organización, herramientas, equipamiento gym casero.
DÍA 1–3
Poner el agente a correr
  • Clonar el código a tu compu
  • Llenar .env con las API keys
  • Correr python main.py --dry-run para verificar
  • Configurar GitHub Actions para ejecución diaria automática
DÍA 4–14
Iterar y observar
El agente produce contenido diario solo. Vos revisás 1 vez por semana. Si ningún video pasa 500 views en 7 días → cambiar nicho. Si algo pasa 5.000 views → el agente lo detecta y replica el formato.
🎯
Expectativa realista Mes 1: USD 0–20 (normal). Mes 2: USD 30–100 si hay tracción. Mes 3–4: USD 100–500/mes si clonaste a 3 nichos. No es lotería, es un sistema lento que se acumula.

🛑 ¿Cuándo matar el experimento?

Reglas claras para no perder el tiempo:

❌
30 días, cero clicks de afiliado, ningún video supera 1.000 views → cambiar de nicho.
⚠️
Cuenta de TikTok baneada 2 veces seguidas → cambiar de plataforma o variar más el output (más estilo humano, menos AI puro).
💸
Gastaste USD 100 en API sin un peso de retorno → bajá el modelo (gpt-4o → gpt-4o-mini) y reducí frecuencia.
✅
Algún video pasó los 5.000 views → es un winner. Dejá al agente replicar el formato, no toques nada.
✅
Primer ingreso de afiliado entró → anotá CUÁL video lo generó. Esa es información de oro para el siguiente ciclo. Ahora pensá en clonar el agente a otro nicho.
🧬
La regla del clon Un agente que genera USD 30/mes no es interesante. Diez clones del mismo agente generando USD 30/mes cada uno son USD 300/mes y siguen siendo cero trabajo tuyo. La replicabilidad es el verdadero multiplicador.
